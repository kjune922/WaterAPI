## 제출 필수 범위
1. 시설 등록, 점검 등록, AI 분석, 결과 조회, 점검 수정 후 이전 분석 제거 흐름.
2. 키 없는 Stub 데모와 OpenAI 실행 분리. 외부 오류와 잘못된 응답 처리.
3. MySQL 관계, 제약, 마이그레이션과 통합 테스트.
4. Docker 이미지, AWS EC2와 비공개 RDS, 제한된 접근, 비밀값 외부 관리. 실제 배포 토폴로지에 맞게 설명하고 고가용성으로 과장하지 않음.
5. 테스트 CI와 수동 배포 구분. 로그, 헬스체크, 롤백과 자원 종료 절차.
6. 코드, 테스트, 실행 기록에 연결된 짧은 포트폴리오.

## 이번 제출에서 제외
Kubernetes, RAG, 벡터 DB, 무인 장애 조치, 완성된 멀티테넌트 SaaS 주장.
공개 데모는 인증과 접근 제한을 갖춘 뒤 공개하며 실제 개인정보 대신 샘플 점검 데이터를 사용.
