# 로컬 실행 검증

검증일: 2026-11-17
환경: Windows, Docker Desktop, Docker Compose, MySQL 8.4

## 확인한 항목

- Docker Compose로 WaterAPI와 MySQL 실행
- MySQL 컨테이너 healthy 상태 확인
- /actuator/health 응답 UP 확인
- 시설과 점검일지 등록, 처리 상태 변경
- stub 프로필에서 분석 결과 저장과 조회
- docker compose down 후 up -d로 재생성
- 재생성 후 점검일지, 처리 상태, 분석 결과와 분석 시각 유지
- Java 시간대를 Asia/Seoul로 설정
- 새 분석 결과의 시각이 한국 시간과 일치함을 확인

## 검증 범위

- Docker 환경의 AI 분석은 stub으로 확인했다.
- Docker 밖의 openai 프로필과 Docker의 prod,openai 프로필에서 실제 OpenAI 분석을 확인했다.
- Docker에서 PUMP-B 점검 내용으로 실제 분석 결과를 생성하고 조회했다.
- 기본 Compose 설정으로 전환한 뒤 새 점검일지에서 stub 분석 결과를 확인했다.
- OpenAI API 키는 PowerShell 환경변수로 전달하고 소스 파일에는 기록하지 않았다.
- AWS 배포는 아직 검증하지 않음.
